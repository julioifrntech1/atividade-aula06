Meu Projeto GitHub

Descrição

Este projeto foi desenvolvido como atividade prática para aprender a utilizar Git e GitHub.

O objetivo é praticar comandos Git, realizar commits e publicar arquivos em um repositório remoto.

Como executar o projeto

Clone o repositório:

git clone https://github.com/julioifrntech1/atividade-aula06.git

Entre na pasta:

cd atividade-aula06

Abra o arquivo README.md no VS Code.
